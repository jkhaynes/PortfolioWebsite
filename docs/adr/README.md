# Architecture Decision Records

One file per significant decision: why this library, this data store, this pattern, this trade-off. Decisions made in AI sessions disappear when the session ends unless they're written down here.

**When to write one:** you chose between real alternatives, or a future reader (or agent) would ask "why is it like this?"

**How:** copy `0000-template.md` to `NNNN-short-title.md` with the next number, fill it in, add a row below. Never edit an accepted ADR's decision; supersede it with a new one.
